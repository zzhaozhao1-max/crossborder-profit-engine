# CrossBorder Profit Engine

An open-source profit analytics engine for cross-border e-commerce sellers.

## Overview

CrossBorder Profit Engine helps global e-commerce sellers calculate real profitability across marketplaces including Amazon, TikTok Shop, Shopee, Shopify and Walmart.

The project focuses on transparent profit analysis instead of simple sales tracking.

## Features

### Profit Calculator
- Product cost calculation
- Shipping cost analysis
- Platform fee calculation
- Advertising ROI calculation
- Refund and return impact analysis
- Multi-currency conversion

### Marketplace Support
- Amazon
- TikTok Shop
- Shopee
- Shopify
- Walmart

### Supported Markets
- United States (USD)
- Vietnam (VND)
- Philippines (PHP)
- Malaysia (MYR)
- Thailand (THB)
