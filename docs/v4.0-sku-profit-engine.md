# V4.0 SKU Profit Engine

## Goal
Calculate real cross-border profit by SKU.

## Flow

Order Revenue
-> Platform Fee
-> Affiliate Fee
-> Ads Cost
-> Refund Loss
-> SKU Cost
-> Net Profit

## Cost Model

SKU contains:
- Product cost
- Shipping cost
- Packaging cost

## Output

- Revenue
- Total Cost
- Profit
- Margin
