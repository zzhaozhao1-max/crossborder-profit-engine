# V2.4 User and Store Management

## Goal

Support multiple cross-border stores under one account.

## User

- Account information
- Store list
- Permissions

## Store

Fields:

- Store name
- Platform
- Country
- Currency
- Fee rule configuration

Supported platforms:

- Amazon
- TikTok Shop
- Shopee
- Walmart
- Shopify

## Flow

User -> Store -> Order Data -> Profit Engine -> Dashboard
