# Regional Marketplace Rules

## Purpose

Provide configurable marketplace fee rules by country and platform.

## Supported regions (initial)

### TikTok Shop Vietnam
- Currency: VND
- Platform fee model
- Affiliate commission model

### TikTok Shop Thailand
- Currency: THB
- Platform fee model
- Affiliate commission model

### Amazon US
- Currency: USD
- Referral fee model

## Future expansion

- Malaysia TikTok Shop
- Philippines TikTok Shop
- Shopee Thailand
- Shopee Vietnam
- Walmart US

Rules will become configurable database records in future versions.
