# Demo Deployment Roadmap

## Goal

Deploy CrossBorder Profit Engine as a public demo for open-source review and user testing.

## Architecture

Frontend:
- React
- Tailwind CSS
- Vercel deployment

Backend:
- FastAPI
- Docker container
- Render/Railway deployment

Database:
- PostgreSQL (future)

## Demo Features

### Profit Calculator

Users can enter:
- Selling price
- Product cost
- Shipping cost
- Marketplace fees
- Advertising cost

Output:
- Revenue
- Total cost
- Profit
- Profit margin
- ROI

### Currency Converter

Supported currencies:
- USD
- CNY
- VND
- PHP
- MYR
- THB

### Order Analytics

Future support:
- CSV upload
- XLSX upload
- Order matching
- Refund analysis
- SKU profitability analysis
