# Marketplace Fee Rules V2

## Overview

Upgrade the platform fee engine from a simple calculator into a multi-marketplace rule system.

## Supported Platforms

- TikTok Shop
- Amazon
- Shopee
- Walmart (planned)

## TikTok Shop

Formula:

Sales Revenue - Platform Fee - Affiliate Fee - Ads Cost = Channel Profit

Parameters:

- Platform commission rate
- Creator affiliate rate
- Advertising cost
- Refund loss

## Amazon

Formula:

Sales Revenue - Referral Fee - FBA Fee - PPC Cost - Return Loss = Profit

Parameters:

- Referral percentage
- FBA fulfillment cost
- Storage cost
- Advertising cost

## Shopee

Formula:

Sales Revenue - Transaction Fee - Service Fee - Ads Cost = Profit

## Future Development
