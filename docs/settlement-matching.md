# Settlement Matching Engine

## Purpose

Match marketplace settlement records with normalized order data to calculate real revenue.

## Flow

Order Data + Settlement Data

↓

Order ID Matching

↓

Fee / Refund Deduction

↓

Net Income Calculation

## Supported Future Platforms

- Amazon Settlement
- TikTok Shop Finance
- Shopee Finance
- Walmart Marketplace

## Output

- Gross Revenue
- Platform Fees
- Refund Amount
- Net Income
- SKU Average Settlement
