# Order Analytics Engine

## Purpose

Analyze cross-border marketplace orders and settlement data.

## Supported Data Sources

- Amazon reports
- TikTok Shop orders
- Shopee orders
- Walmart orders
- CSV/XLSX settlement files

## Core Functions

### Order Matching

- Match order ID
- Match payment records
- Handle multi-SKU orders
- Remove duplicate settlement records

### Sales Analysis

Calculate:

- Total shipped orders
- Returned orders
- Valid sales quantity
- SKU average settlement amount

### Profit Analysis

Formula:

Revenue - Product Cost - Shipping - Platform Fees - Advertising Cost - Refund Loss = Net Profit
