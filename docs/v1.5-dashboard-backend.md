# V1.5 Dashboard Backend Integration

## API Modules

### Summary

GET `/api/dashboard/summary`

Returns:

- revenue
- profit
- margin
- ROI
- currency

### Product Analytics

GET `/api/dashboard/products`

Returns SKU performance data.

## Data Flow

Frontend Dashboard

↓

FastAPI Dashboard API

↓

Profit Engine / Order Analytics Engine

↓

Analytics Result
