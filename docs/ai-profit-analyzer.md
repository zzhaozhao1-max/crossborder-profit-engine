# AI Profit Analyzer

## Purpose

Analyze changes in cross-border ecommerce profitability and provide operational suggestions.

## Input

- Revenue
- Product cost
- Shipping cost
- Platform fees
- Advertising cost
- Refund rate
- Exchange rate changes

## Analysis Flow

```
Business Data
      ↓
Profit Comparison
      ↓
Cause Detection
      ↓
Optimization Suggestions
```

## Example

Problem:

Profit decreased 20%

Possible reasons:

- Advertising cost increased
- Refund rate increased
- Currency fluctuation

Suggestions:

- Optimize ads ROI
- Improve product listing
- Review pricing strategy
