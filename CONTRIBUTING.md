# Contributing

Thank you for contributing to CrossBorder Profit Engine.

## Development Principles

- Keep features practical for real e-commerce sellers.
- Write clear documentation.
- Add tests for new calculation logic.
- Avoid exposing private business data.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Submit a pull request.
4. Describe your changes clearly.

## Areas We Welcome

- Marketplace fee models
- Currency conversion improvements
- Data analysis features
- UI improvements
- Documentation
